# ☕ Core Java Learning Repository  

Welcome to the **Core Java** repository! 🚀  
This project is a **collection of Java programs, exercises, and assessments** designed to help you learn and practice **Java fundamentals** in a structured way.  

Whether you’re a **beginner** starting with Java, or someone **brushing up concepts** for interviews & projects, this repo will guide you step by step.  

---

## 📌 Topics Covered  

### 🔹 Basics
- Variables, Data Types, Operators  
- Control Statements (if-else, switch, loops)  
- Arrays & Strings  

### 🔹 Object-Oriented Programming (OOP)
- Classes & Objects  
- Inheritance  
- Polymorphism (Compile-time & Runtime)  
- Abstraction  
- Encapsulation  

### 🔹 Exception Handling
- try-catch-finally  
- throw & throws  
- Custom Exceptions  

### 🔹 Multithreading
- Thread creation & lifecycle  
- Synchronization  
- Inter-thread communication  
- Real-world examples  

### 🔹 Assessments
- Small coding problems & exercises after each module  
- Helps in **self-assessment** and **interview preparation**  

---

## 📂 Repository Structure  

```
CORE-JAVA/
│── BASIC/                        # Java basics (syntax, loops, arrays, strings)
│── OOPS/                         # Object-Oriented Programming concepts
│── OOPS_Assessment/              # Practice exercises for OOP
│── Exception_Handling/           # Exception handling examples
│── Exception_Handling_Assessment/# Practice exercises for exceptions
│── Multithreading/               # Threads & concurrency examples
│── Multithreading_Assessment/    # Practice exercises for multithreading
│── .github/                      # GitHub workflows (automation)
│── .metadata/                    # IDE metadata (can be ignored)
```

## 🛠️ How to Use  

1. **Clone the repository**  
   ```bash
   git clone https://github.com/abhirazz123/CORE-JAVA.git
   ```

2. **Open in your favorite IDE** (IntelliJ IDEA / Eclipse / VS Code).  

3. **Run Java programs** inside each module to explore concepts.  

4. **Try the assessments** to test your knowledge and prepare for interviews.
